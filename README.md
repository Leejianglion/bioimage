# 共聚焦图片 FI–浓度分析（同一 ROI）

从 PPT 里读取“浓度标签在上、共聚焦图片在正下方”的排版，然后：

1. **核对浓度 ↔ 图片的对应关系**：只有“正上方唯一的浓度标签”才算确定；有任何不确定（一个标签下面两张并排的图、两个标签指向同一张图、没有标签、一个文本框写了好几个浓度）都会列出来，不猜。
2. **每张图取完全相同的区域（ROI）**测平均荧光强度（FI），同一个通道，不做逐张的亮度/对比度/背景调整。
3. **检查会让 FI 不可比的问题**：饱和像素、0 值像素、合成图（merge）通道、PPT 里的亮度/对比度调整、PPT 裁剪、比例尺/文字标注、重复使用的图片、JPEG 导出。
4. **出现“浓度更高（看起来更亮）但 FI 更低”时，逐条给出原因。**
5. 读取第 2–3 页已有的 ≥10 ng/mL 结果，拟合饱和曲线（F = F0 + Fmax·C/(K + C)），检查新测的低浓度数据能否和已有结果衔接。

## 使用

```bash
pip install -r requirements.txt
python -m fi_analysis 你的文件.pptx -o results
```

常用参数：

| 参数 | 含义 |
|---|---|
| `--roi 0.1,0.1,0.8,0.8` | ROI = x,y,宽,高（占图片宽高的比例），所有图片相同。默认取中间 80%，避开四角的比例尺/文字 |
| `--channel auto\|R\|G\|B\|gray` | 分析通道；`auto` 选总信号最强的通道，所有图片用同一个 |
| `--ref-slides 2,3` | 已有结果所在的页（默认第 2、3 页） |
| `--reference reference.csv` | 已有结果无法自动读取时，手动提供：列为 `conc,fi,sd` |
| `--no-render` | 不用 LibreOffice 渲染幻灯片（渲染用于目视核对对应关系） |

**推荐用原始共聚焦文件**（PPT 里的图是导出图，可能调过显示）：

```bash
python -m fi_analysis --images 原始图片文件夹 --map map.csv -o results
```

`map.csv` 的列为 `file,conc,unit`，例如 `img01.tif,0.1,ng/mL`。支持单层或单通道 TIFF（Fiji 里“Save As → Tiff”，不要改位深）。

## 输出（`results/`）

| 文件 | 内容 |
|---|---|
| `summary.md` | 报告：对应关系、质控、测量值、倒挂原因、拟合、与已有结果的衔接、需要你确认的事 |
| `slides/slide-XX-mapping.png` | 每页幻灯片上标出每张图被分配的浓度和状态（绿 = 确定，黄 = 需确认，红 = 未分配） |
| `roi_sheet.png` | 所有图按浓度排好，**同一个固定显示范围**（不自动对比度），画出 ROI |
| `dose_response.png` | 已有结果 + 拟合 + 本次测量（有共同浓度时换算到已有结果的刻度） |
| `mapping.csv` / `measurements.csv` / `per_concentration.csv` | 明细表 |
| `deck_content.md`、`charts/*.xlsx` | PPT 每页的文字、表格、图表数据（用于核对第 2–3 页） |
| `images/` | 从 PPT 里取出的原始嵌入图片 |

## 固定规则

- 所有图片同一 ROI、同一通道；不逐张调整，也不为了“符合预期”去挪 ROI 或换指标。
- 拟合曲线**只用来检查**测量值，不用来生成没有测量过的浓度的数值。已有数据最低是 10 ng/mL 时，曲线在 10 以下是外推，F0（零浓度本底）并没有被数据约束。
- 新旧两组数据要画在同一条曲线上，必须有**共同浓度**做桥接（例如低浓度这批里同时测一个 10 ng/mL），否则两组灰度不在同一个刻度上。
- 每个浓度只有一张图时没有生物学重复，排序差异无法做统计判断；“空间SD”只是同一张图里换位置的波动。

## 为什么会出现“更亮但 FI 更低”

在**同一套采集参数、同一个 ROI、同一个通道**下，更亮的图平均灰度一定更高——这是 FI 的定义。所以出现倒挂，说明比较的条件其实不一样，常见原因（程序会逐条检查）：

1. **显示调整 ≠ 像素值**：PPT 或导出时改过亮度/对比度/显示范围，看到的亮度不是被测量的像素。
2. **采集参数不同**：拍高浓度时调低了激光或增益（HV）以免过曝，原始灰度就会更低。导出图里看不出来，要看原始文件的元数据。
3. **饱和**：高浓度像素顶到 255/4095 被截平，FI 被低估。
4. **细胞数量/覆盖面积不同**：单个细胞更亮但细胞更少，整块区域的平均值反而更低。
5. **测错通道**：合成图（merge）里混入了 DAPI/明场等其它通道。
6. **平台期的正常波动**：饱和后各浓度真实值几乎相同，单张图的差异可能小于取样误差，需要多视野重复。
7. **图片和浓度对错了**：标签位置不在正上方，或同一张图被用了两次。

```bash
python -m pytest -q tests
```

测试用合成的 PPT（已知答案）覆盖：标签解析、组合形状中的图片、PPT 亮度调整、比例尺排除、重复图片、一个文本框多个浓度、不确定/冲突/无标签的情况、图表数据读取、拟合与桥接、三种倒挂原因。
